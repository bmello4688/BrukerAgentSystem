# TripleQuadUI Shared Agent Status Board

This board is the shared status surface for local TripleQuadUI agents. Keep it outside the Bruker Detection Git repo.

## Board Rules

- Every agent must append or update this file when it starts work, changes state, is blocked, hands off, or finishes.
- Keep entries concise and operational. Put long evidence in the relevant spec, memory, log file, or review note, then link the path here.
- Do not include credentials, customer data, private contact details, raw runtime IDs, or sensitive local-only transcript content.
- If a change affects `source/TripleQuadUI`, include branch/worktree, claimed files, validation, and next action.
- Prefer updating an existing active item instead of adding duplicate items for the same work.

## State Legend

- Ready: shaped enough for an agent to pick up.
- Active: an agent is currently working it.
- Blocked: waiting on human input, hardware/simulator, credentials, unavailable service, or another agent.
- Review: implementation or analysis is ready for review/integration.
- Done: completed and no follow-up is required.
