# Specs

Store shaped feature specs here before implementation.

Use timestamped folders:

```text
agent-os/specs/YYYY-MM-DD-HHMM-feature-slug/
  plan.md
  shape.md
  standards.md
  references.md
  tasks.md
  visuals/
```

Each spec should identify:

- Feature owner or agent.
- Source repos affected.
- Acceptance criteria.
- Test plan.
- Integration and release notes.
